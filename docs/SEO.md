# GrowtechAxon SEO baseline
- Page-specific title, description, canonical and social metadata.
- `robots.txt` and XML sitemap.
- Organization, WebSite and WebPage JSON-LD on the homepage.
- Dedicated service, solution and training URLs instead of hash-only routing.
- Semantic headings, descriptive image alt text and lazy loading.
- WebP derivatives for large portfolio assets.
- Internal links between services, solutions, projects, training, FAQ and contact.
- Admin and API paths are excluded from crawl directives.
- Before launch, submit the production sitemap in Google Search Console and verify canonical URLs after deployment.
